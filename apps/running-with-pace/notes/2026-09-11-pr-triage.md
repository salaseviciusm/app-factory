  await is load-bearing — main's own comment says *"Awaited so publish() resolves only
  after the event is durable — needed for post-stop flush."* Merging #44 would unpick the
  durable-subscribe contract. Its map/overlay rewrites would also fight the Mapbox switch

  since the merge-base, `RunEndingScreen.tsx` +393/-468, `AnalyticalModeOverlay.tsx`

- **Worth salvaging:** exactly one hunk, two lines, in `src/utils/run-stylers.ts` —
  guard `drawSegmentsOnMap` against degenerate segments:
  `if (!segment.visible || segment.line_path.length < 2) return;`. Main still has the
  unguarded `if (!segment.visible) return;`. That file does not conflict.
- **Call:** close #44. Land the two-line `run-stylers.ts` guard as its own trivial PR.
