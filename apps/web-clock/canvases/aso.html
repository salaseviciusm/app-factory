Apple 4.3 defense

Not a reskinned WOD timer and not another N-exercise AI counter. The custom value is a single-benchmark specialist: on-device Vision detectors for the 5-10-15 circuit, a clock that scores rounds the way the workout is scored, a framing gate, and undercount-when-unsure. The template is the shell. The detectors and the score are the app.

That defense dies if we ship a tap counter with a red theme, or if we put Spider-Man on the icon. Trademark and 4.3 are the same decision: ownable name, concrete capability, no film IP.

Reasons not to build — still on the table

The timer already exists

Two Cindy timers shipped this year to zero ratings. Counting-by-tap is not a business. If Vision cannot hold three moves from one propped phone, this is a don’t-build.

Camera count has not sold everywhere

Skip-hero’s own research: five camera jump-rope apps, 44 US ratings combined. GOLDEN Bars is the pull-up specialist at 7. Push-ups are the exception. We are betting the benchmark + clock is the missing half.

One camera, three planes

Pull-ups want ¾/front and ignore hips. Squats need hips/knees. 3D hips are templated (pullup spike 002). Side/¾ standing full-body is a v1 requirement, not a suggestion.

Founder calls before we implement UI

1. Name — default Web Clock. Alt: “5-10-15” (searchable, less ownable). Reject: any Spider-Man / Holland / Brand New Day string on the store.
2. Workout — default Cindy 5-10-15 × 20:00. The short also shows a one-legged drill. We wait for tomorrow’s raw clips before adding a fourth detector.
3. Money — default free live set, paid history. Hard paywall only if you want Rank 0 closer to the skip-hero F0 recommendation. I would not gate the aha.
4. Scaled Cindy in v1? Default no. Banded / knee / 3-6-9 is a data table on the same director, but it dilutes the listing. Ship Rx first.
